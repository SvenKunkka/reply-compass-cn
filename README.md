# 回得刚刚好

## English Overview

Reply Compass is a privacy-first assistant for writing tactful follow-up messages. Paste chat text or a screenshot, choose the relationship, situation, and desired level of urgency, and the app produces three alternatives: gentle, balanced, and direct. Each option explains its wording and includes a suggested next step if the other person still does not respond.

Text extraction and reply analysis run in the browser. The current version has no account system, database, or server-side chat API, and it does not save or upload conversation content. On first use, Tesseract.js may download OCR runtime files and language data from its public asset source. Users should remove names, contact details, order numbers, and other sensitive information before sharing examples in public Issues.

The project uses React, Vinext, Tailwind CSS, and Tesseract.js. Reply suggestions are generated by local scenario rules rather than a hosted language model. Node.js 22.13 or newer is required; run `npm install` and `npm run dev` to start the local development server.

一个隐私优先的催促回复助手。粘贴聊天文字或截图，选择双方关系和推进力度，即可获得柔和、平衡、明确三档回复建议。

项目主页：[github.com/SvenKunkka/reply-compass-cn](https://github.com/SvenKunkka/reply-compass-cn)

## 功能

- 直接粘贴聊天记录或聊天截图
- 在浏览器中识别中英文截图文字
- 根据关系、场景和紧急程度生成三档回复
- 解释措辞逻辑并提供二次跟进建议
- 一键复制回复
- 支持桌面和手机屏幕

## 隐私

当前版本没有账户、数据库或服务端聊天记录接口。截图 OCR 和回复分析均在用户浏览器中运行，项目不会保存或上传聊天内容。首次进行截图识别时，Tesseract.js 可能从其公共资源源加载 OCR 运行文件和语言数据。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开终端中显示的本地地址即可使用。

## 构建

```bash
npm run build
```

## 技术说明

项目使用 React、Vinext、Tailwind CSS 和 Tesseract.js。当前回复生成采用浏览器内的场景规则，不调用联网大模型，适合作为可直接使用的隐私优先版本，也便于后续替换为自托管模型或经过用户授权的 AI 接口。
